### blare

Error alerting for Python and Node.js. Fire the same exception five hundred
times and you get one message, not five hundred — which is the whole point,
and the thing most alerting tools get wrong.

No server, no database, no dashboard. Zero runtime dependencies in both
languages, because a library that sits in someone else's production path has no
business dragging a tree in with it. The two implementations are held to one
written spec by 90 conformance tests, so they can't quietly drift apart.

```bash
pip install blare        # or: npm i @geekvb/blare
```

Apache-2.0 · [PyPI](https://pypi.org/project/blare/) · [npm](https://www.npmjs.com/package/@geekvb/blare) · [spec](https://github.com/D4RKGEEK/blare/blob/main/SPEC.md) · [live demo](https://d4rkgeek.github.io/blare/)

### tempolight

Music-reactive lighting that understands the song, not just the volume — the
beat, the bars, the build-ups and the drops. Every LED in the room is one
canvas: strips, rings, frames, poles and matrices.

Zero dependencies again. Runs on Windows, macOS, Linux and a Raspberry Pi.

MIT · [repo](https://github.com/D4RKGEEK/tempolight)

### How I work

I measure what I claim. Not "it feels synced" but the phase error in beats. A
test proving the output is finite and in range will pass happily while the
thing renders solid black — that caught me four times, so now I render it and
look.

Finished means a spec, a licence, CI and a demo a stranger can run in under a
minute. Otherwise it isn't done, it's working on my machine.

I'd rather be corrected than agreed with.
